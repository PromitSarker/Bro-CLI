---
title: "Uni-CLI vs OpenCode models"
description: "Understand the difference between Uni-CLI inference and OpenCode Go or Zen models"
---

Uni-CLI and OpenCode are different model providers. A subscription or API key for one does not automatically give access to the other.

| Provider | Where to manage it | What it controls |
| --- | --- | --- |
| Uni-CLI inference | [Uni-CLI inference dashboard](https://app.uni-clilabs.com/dashboard/inference) | Uni-CLI-managed model access and organization usage limits |
| OpenCode Go / Zen | [OpenCode Go](https://opencode.ai/go) and [OpenCode auth](https://opencode.ai/auth) | OpenCode-managed models, subscription, and API access |

## How to tell whether you are subscribed to Uni-CLI inference

Open the [Uni-CLI inference dashboard](https://app.uni-clilabs.com/dashboard/inference).

- If the page shows `Subscribe`, you are not subscribed to Uni-CLI inference.
- If the page shows usage limits and usage remaining, you are subscribed to Uni-CLI inference.

## How Uni-CLI usage buckets work

Uni-CLI inference usage is tracked with separate usage buckets. You may see buckets such as:

- `5 hour usage limit` — a short-term bucket that resets during the day.
- `Weekly usage limit` — a weekly bucket that resets on the listed date.
- `Monthly usage limit` — a monthly bucket that resets on the listed date.

The dashboard shows how much remains in each bucket and when each bucket resets. Usage is shared across your whole Uni-CLI organization, not just your personal desktop app.

Organization limits scale with the number of active members in the org. For example, adding active members increases the shared organization allowance, and usage by any member draws from the same shared buckets.

## If you meant to use OpenCode models

Connect the `OpenCode Go` provider in Uni-CLI Desktop instead of using Uni-CLI inference. Follow [Using OpenCode Zen & Go Models](/start-here/connect-your-stack/using-opencode-zen-go-models) to add the provider.

Use these OpenCode links to manage that account:

- [opencode.ai/go](https://opencode.ai/go)
- [opencode.ai/auth](https://opencode.ai/auth)
