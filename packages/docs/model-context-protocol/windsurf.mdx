---

Give Windsurf your organization's Uni-CLI skills, plugins, and connections.

<Steps>
<Step title="Open the raw MCP config">
Open `Settings` > `Cascade` > `MCP Servers` > `Manage MCP Servers` > `View raw config`.
</Step>
<Step title="Add the server">
Add this to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "uni-cli": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://api.uni-clilabs.com/mcp/agent"]
    }
  }
}
```

</Step>
<Step title="Sign in">
`mcp-remote` opens the browser. Sign in to Uni-CLI and pick your organization.
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `uni-cli` token, restart the server, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Uni-CLI's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
