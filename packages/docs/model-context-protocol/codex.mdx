Give Codex your organization's Uni-CLI skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
codex mcp add uni-cli --url https://api.uni-clilabs.com/mcp/agent
```

In the Codex desktop app, paste the URL in `codex://settings/connections` instead.

</Step>
<Step title="Sign in">

```sh
codex mcp login uni-cli
```

Sign in to Uni-CLI in the browser and pick your organization.

</Step>
<Step title="Try it">
Ask: "Which Uni-CLI organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">

```sh
codex mcp logout uni-cli
codex mcp login uni-cli
```

  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Uni-CLI's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
