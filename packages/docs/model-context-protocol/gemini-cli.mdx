Give Gemini CLI your organization's Uni-CLI skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
gemini mcp add --transport http uni-cli https://api.uni-clilabs.com/mcp/agent
```

</Step>
<Step title="Sign in">
Start `gemini`, run `/mcp auth uni-cli`, sign in to Uni-CLI in the browser, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which Uni-CLI organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `uni-cli` token, run `/mcp auth uni-cli` again, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow Uni-CLI's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
